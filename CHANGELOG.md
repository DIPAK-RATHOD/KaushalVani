# Changelog

All notable changes to the KaushalVani project are documented in this file.

## [1.0.0-MVP] - 2026-09-24

### Added
- Modular monolith architecture with Node.js Express API gateway and Python FastAPI AI engine.
- Multilingual voice recognition with Web Speech API streaming ASR and BHASHINI API proxy.
- Transparent NQR NSQF qualification mapping with official source provenance links.
- PostGIS / Haversine geospatial proximity training centre matching.
- Dynamic 7-step Personalized Livelihood Roadmap output generator.
- Government Official Dashboard with cohort funnels, sector demand charts, and outcome tracking.
- UX4G & GIGW accessibility toolbar supporting text scaling, high contrast theme, and audio read-aloud.
- Automated integration test suite covering 6 evaluation personas.
